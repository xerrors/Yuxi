# 使用文档回收站

面向知识库管理员；前置条件为已登录并拥有该托管知识库管理权限。目标是移入、查看和恢复文件，不包含整库恢复。

## 前端入口

打开「个人空间」页头的「统一回收站」，可以同时查看本人的个人文件、正式会话附件，以及有管理权限的托管知识库文档。也可直接访问 `/trash`。

知识库内入口仍保留：管理员选择托管知识库→文件列表右上角「回收站」。外部只读来源不显示知识库回收入口。

- 文件列表的「删除」现在移入回收站，文件夹会包含后代；批量选择中任一文件正在处理时，整批不执行并提示原因。
- 抽屉显示文件名、删除日期、到期时间、状态及「恢复」按钮，每页10项。
- 30天内恢复到原目录，原索引保留。上级目录尚在回收站时先恢复上级；原目录存在同名文件时先重命名活跃文件，不自动覆盖。
- 到期或开始物理清理后禁用恢复。首次不提供「立即永久删除」按钮。
- 回收站仍占用存储；有回收站项目或原件仍被其他知识库引用的知识库禁止整库删除，避免绕过保留期。


清理机制见[回收站生命周期](../mechanisms/document-trash.md)，发布要求见[回收站升级](../advanced/document-trash-upgrade.md)。

## 个人文件与会话附件

个人空间或文件查看器删除文件、目录时移入回收站；删除正式会话附件也进入同一列表。未确认的临时上传仍按临时文件规则删除，不进入30天回收站。

「我的个人文件与会话附件」仅本人可见，即使管理员也不查看其他人的个人回收记录。恢复保留原位置，不覆盖后来上传的同名文件。处理中断显示状态和重试入口，到期或清理中的文件不可恢复。

有排队或正在执行的智能体任务时，个人删除/恢复操作先提示等待。由于旧聊天和摘要没有可靠的逐文件来源信息，删除个人文件后可能引用它的旧会话会暂停后续模型调用；可恢复该文件或新建会话，原聊天记录仍可查看。独立保存的记忆文本不自动擦除。
