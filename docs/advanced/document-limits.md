# 知识库文档处理限制

本文供超级管理员和部署维护者查阅。知识库上传界面显示有效单文件大小和PDF页数；超级管理员在「账户设置 → 基本设置 → 文档处理限制」保存、重新加载或恢复默认值。操作按钮位于字段下方。保存冲突时先重新加载，再重新输入。

## 范围与生效时机
设置作用于知识库文件上传、URL内容获取、工作区导入和这些文档的解析。接收读取数据库有效限额；新解析任务在入队时固定快照，任务重试沿用该快照。客户端解析参数不得扩大快照。没有快照的升级前任务保持原行为。

大小单位为MiB（1,048,576字节）。PDF在解析前检查总页数，文字PDF也受限制。其他文档按字节限制。个人文件上传、聊天附件和外部OCR服务本身的限制不由此页面修改。

## 部署参数
| 参数 | 默认 | 读取者与含义 |
|---|---|---|
| `DOCUMENT_UPLOAD_MAX_MIB` | 100 | API默认单文件限额；恢复默认后使用 |
| `DOCUMENT_OCR_MAX_PAGES` | 500 | API默认PDF页数限额 |
| `DOCUMENT_UPLOAD_HARD_MAX_MIB` | 100 | API与生产Web代理的硬上限；网页不得扩大 |
| `DOCUMENT_OCR_HARD_MAX_PAGES` | 500 | API的PDF页数硬上限 |

Compose将后端参数传给API和worker；生产Web按同一字节硬上限加1MiB的multipart余量生成nginx配置。硬上限收紧后，后续接收使用配置和硬上限中的较小值，页面显示实际值。修改环境变量需重建相应容器，上层反向代理也需协调请求大小。提高数值前确认OCR、内存、并发和存储容量；此配置不扩充外部服务能力。

## 错误与恢复
读取限制失败时上传不继续；非整数、零或超过硬上限的保存请求被拒绝。数据库提交后使缓存失效，接收边界直接读数据库，不依赖缓存失效成功。解析超限进入既有任务错误路径，管理员调整限额后可重新提交解析任务。
