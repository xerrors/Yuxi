# Yuxi 0.8.0：面向企业智能体基座进化

Yuxi 0.8 围绕企业使用智能体的完整过程展开升级：将业务知识接入任务，让多个智能体分工协作，在关键环节保留人的参与，并把成果、来源和执行记录留在同一工作空间。

这个版本的重点，是让智能体能力更容易融入企业业务、更容易沉淀复用，也让复杂任务的执行更可控。开放集成、团队治理、多智能体协作、知识溯源与底层架构共同构成了这次演进。

当前版本为 `0.8.0`。默认部署步骤见[快速开始](../../intro/quick-start.md)。

## 一、面向企业智能体基座进化

从团队内部的专属助手，到嵌入业务系统的智能体服务，0.8 进一步打通身份、能力、知识与应用之间的连接。

### 开放接入，让智能体融入已有业务

- **将智能体接入业务应用与自动化流程**：统一的 Public API 和全新 npm CLI 提供会话、任务提交与流式结果入口，支持附件及图片输入，让网页之外的应用和脚本也能使用 Yuxi 的智能体能力。设置中的 API 接入页集中展示 APP 凭据、使用统计和接口示例，知识库提供同源 MCP 接入指引。
- **让企业知识服务于更多 Agent**：内置知识库 MCP 服务，向外部客户端开放知识检索、文件查找和正文阅读。外部 Agent 可以在用户授权范围内使用 Yuxi 知识，无需单独部署知识 MCP 服务。
- **连接员工自己的工具账号**：远程 MCP 支持个人 OAuth 授权、Bearer Token 与 API Key，每位用户可以连接自己的资源账号，平台统一管理服务入口。企业登录与外部工具授权分别管理，适配范围见 [MCP 集成](../../agents/mcp-integration.md)。

### 团队治理，让能力共享有边界

- **融入企业身份体系**：完善 OIDC 登录与账号绑定，区分平台用户和业务应用终端用户；应用之间的会话、附件与执行按 APP 隔离。智能体支持私有使用和授权共享，工具、知识库与 Skills 按当前用户权限使用。
- **把业务经验沉淀为可复用能力**：智能体可绑定专属 Skill，将操作方法、脚本和模板一起交付；支持完整包在线编辑、专属 Skill 发版与历史恢复，方便团队维护和迭代自己的业务助手。
- **看清平台使用与改进方向**：管理概览汇总智能体、模型、工具和 Token 使用趋势，并可配合模型网关按用户归集用量。结合用户反馈、Agent 改进线索和整轮任务调试，帮助团队了解使用情况、定位改进方向。
- **呈现企业自己的品牌**：产品名称、Logo、首页口号与登录背景统一配置，让任务入口与企业品牌保持一致。

接入指南：[Agents API](../../intro/agents-api-quickstart.md) · [CLI](../../intro/cli.md) · [知识库 MCP](../../advanced/knowledge-mcp.md) · [企业登录](../../advanced/third-party-auth.md) · [Skills 管理](../../agents/skills-management.md)

## 二、多智能体协作，推进复杂任务交付

研究、分析与内容制作往往需要多种能力配合。0.8 将分工协作、人工引导与成果呈现串联起来，让用户能够持续参与任务推进。

- **多个智能体，围绕同一个项目工作**：协作成员拥有独立上下文和会话，可以分派任务、互发消息、等待并汇总结果，共享项目文件。用户可提及已有智能体参与分工；管理员可按部署容量调整协作深度与并发名额。
- **复杂过程看得见，关键环节接得住**：协作面板展示成员层级、状态和人工待办，用户可以直接进入成员会话回答问题、处理审批或调整要求，减少在多个执行过程之间寻找信息的负担。
- **追加任务与调整方向各有入口**：普通消息按顺序排队，运行中可以发送优先引导；待处理输入支持逐条取消或转为引导，也可停止整组协作并在需要时继续队列。引导在安全执行边界生效，已完成的外部操作不会自动撤销。
- **从资料输入到成果交付更连贯**：支持多图输入和保留目录结构的文件夹上传；回答可组合图表、图片与图文卡片，简短表单帮助一次收集任务条件，文件交付物可继续预览与下载。
- **切换会话，也能接着工作**：会话草稿、侧栏与阅读位置随任务保留，实时输出与历史读取衔接。智能体被删除或撤回访问后，用户仍可在原有权限范围内查阅自己的历史工作记录。

了解更多：[会话协作](../../agents/session-cooperation.md) · [工具与交付](../../agents/tools-system.md)

## 三、知识服务升级，让答案有据可查

企业知识的价值，既在于找到相关内容，也在于让使用者能够核对依据。0.8 将检索、阅读与来源追溯连成更完整的知识使用体验。

- **兼顾语义理解与精确查找**：知识库支持向量、BM25 和混合检索，并提供必含词、排除词、完整短语与命中高亮，兼顾自然语言问题，以及术语、型号、编号等精确查询。
- **从答案直达原文依据**：来源胶囊支持引用预览与文档定位，正文行号连接检索片段和原文阅读。来源标注可独立选择模型，按需处理已完成回答中的正文、图片与表格；标注失败可重试，不改写原回答。
- **直接使用已有飞书知识**：新增飞书知识库只读连接，在线搜索指定知识空间并读取新版普通文档正文，减少维护本地文档副本的工作。连接使用管理员配置的身份权限，适用文档类型见[知识库 API](../../advanced/knowledge-base-api.md)。
- **让知识资产更易组织和维护**：目录上传、移动与重命名采用统一的目录规则，文件状态摘要集中呈现待处理、处理中和失败情况，帮助管理员快速发现入库问题。
- **让文档处理适应不同资料**：补充旧版 Excel 多工作表解析与离线 HTML 正文提取；MinerU 支持选择自托管解析后端、处理强度或官方解析模型，便于按资料特点配置处理方式。

使用指南：[知识库入门](../../intro/knowledge-base.md) · [文档处理](../../advanced/document-processing.md) · [知识图谱](../../advanced/knowledge-base-graph.md)

## 四、架构焕新，让智能体运行更可靠

能力越丰富，越需要清晰的运行基础。0.8 对任务执行、知识接入和部署装配进行系统梳理，为持续扩展与问题定位建立更明确的边界。

- **以持久任务记录支撑长流程**：输入接收、排队、执行与最终结果围绕统一的会话和任务模型组织。任务状态持久保存，审批、引导和协作等待能够接续；异常退出有恢复处理和可查询的失败结果，便于追踪任务停在哪里。
- **执行环境按场景选择**：默认 Container 为每段执行创建临时容器，在可信代码、单租户或本地开发场景下无需 KVM；显式选择 Cube 时，每位用户拥有可跨会话复用的持久虚拟机。两者共用文件工具、审批与审计，停止和接续都纳入执行清理流程。
- **完整知识平台与轻量智能体部署按需选择**：默认提供知识库、图谱和评估能力，也可通过部署配置关闭相关组件，减少服务依赖；已有数据与待处理任务保留，重新启用后继续使用。知识访问统一走 MCP，由知识服务复核用户权限与会话选择。
- **模块职责更清晰，扩展与维护更有依据**：后端按业务域划分用例、持久化与基础设施，前端明确页面、业务模块和共享组件边界；统一初始化负责部署准备，独立就绪检查确认服务是否具备接流量条件。
- **把可靠性检查带入日常交付**：常规 CI 使用容器执行环境验证真实任务链路，覆盖排队、引导、审批、协作与故障恢复；Cube 保留独立验证入口。单个远程 MCP 服务故障可被隔离并显示原因，减少对普通对话的影响。

## 其他更新

- **会话引用与输入**：输入 `@` 可按标题搜索并引用历史对话，引用保留可读标题，同名对话仍可区分；智能体与对话候选各最多显示 5 个，对话排在智能体后面。引用头像、名称与正文使用一致的行内对齐。
- **工作空间与导航**：个人空间新增文件、文件夹拖拽上传及工具栏快捷入口；新建项目可留空名称并自动使用目录名；对话侧栏支持悬浮查看或固定，并改善刷新后的导航恢复。
- **首页与个人体验**：首页任务输入可跨登录跳转保留为会话草稿；账户设置新增近一年个人消息活动热力图，涵盖用户、模型与工具消息；暗色界面通过背景色阶区分页面、卡片与输入框，减少装饰边框和阴影，并使用白色发送按钮；用户管理筛选支持多选后确认，改善定时任务编辑体验。
- **模型与网络搜索**：新部署的内置默认模型更新为 DeepSeek V4.1 Flash，已有配置保持原选择；模型检查直接显示结果并支持重试；统一管理 Tavily、DeepSeek、豆包等网络搜索及正文读取配置，各供应商能力范围见[工具系统](../../agents/tools-system.md)。
- **Skills 使用**：支持中文及带空格的展示名导入，安装失败提示更具体；新建默认助手预加载对话组件与知识检索 Skill；Memory 设置补充查看入口，未保存偏好时默认开启。
- **安全设置**：超级管理员可在独立页面维护知识库 URL 导入和远程 Skill 来源白名单，清空列表可关闭对应能力；URL 导入失败显示具体原因，配置后对新请求生效。
- **调试与运维**：调试面板新增测试用例库，可按完整任务轮次查看执行并跳转 Langfuse；优化执行环境空闲休眠、资源观察与知识文件处理统计。
- **解析与依赖维护**：完善 PDF 预览、文档图片资源与图谱抽取的异常处理，更新文档解析、MCP、前端渲染等依赖的安全补丁，并整理部署和开发文档。

## Bug 修复

### 关键修复：安全、任务连续性与结果正确性

- **权限与网络安全**：修复知识库 URL 抓取中的 DNS 重绑定风险，加强私网与云元数据地址拦截；修复撤销 Skill 授权后依赖工具仍可能执行的问题。后者属于 0.8 开发期优化引入的回归，因涉及权限边界，仍列为关键修复。
- **解析依赖安全**：升级 PDF 与 ASN.1 解析依赖的安全补丁，修复恶意输入导致长时间解析或大量内存占用的问题。
- **任务停止与协作恢复**：修复停止后迟到调用继续派工、清理未完成即恢复、多个协作等待无法接续，以及审批失败回滚后续运行状态的问题，避免任务失控或停滞。
- **失败状态与上下文完整性**：修复模型重试耗尽或摘要失败时错误被当成正常结果的问题，以及工具失败、权限拒绝与页面结果不一致、断流后持续等待的问题；同时修复 OCR 临时文件导致解析前失败的问题。
- **专属 Skill 的运行快照**：修复在线编辑专属 Skill 改变当前任务预加载正文的问题，正在运行的任务保留准备内容，新任务使用编辑后的内容。
- **知识数据一致性**：修复入库中断导致元数据与索引不一致、已删除文件仍出现在检索结果中的问题；统一目录与同级重名规则，修复并发导入及重复登记问题。
- **答案与交付物对应关系**：修复重排分数与文档错配、文件预览下载与智能体实际读取内容不一致，以及附件、图片在排队或切换会话时归属错误的问题；修复最终回答被过程折叠隐藏的问题。

### 体验细节与开发期修复

修复会话引用中的协议标记和内部 ID 出现在自动标题中的问题，命名超时或失败时也使用可读标题。模型名称在紧凑选择器中只显示最后一段，留空的智能体模型显示“使用系统默认”。智能体编辑弹窗统一保存入口并收紧导航和表单间距，账户角色、技能卡片和设置文案按浅深色主题一致展示。

合并修复输入法回车误发送、快速切换预览或搜索时的迟到响应、图文组件嵌套布局、设置页按钮遮挡，以及排队引导按钮、滚动和间距等交互问题。多图输入交接、重试中间件导出遗漏，以及测试夹具、缓存和 CI 装配等开发期配套修正一并收拢，不重复计为新增能力。

## 部署与兼容提醒

- **网页默认完全信任工具执行**：新会话、审批模式选择器与定时任务默认使用“完全信任”，敏感工具可自动执行；已明确保存的审批选择继续生效，也可切回“请求审批”。省略审批字段的外部 API 调用行为保持原契约。
- **部署与数据库兼容**：0.8 面向全新部署，不提供从 0.7.x 原地升级的程序。当前数据库基线为 business 2 / knowledge 2；已有 0.8 business v1 数据库按 [MCP 升级说明](../../agents/mcp-integration.md#已有部署升级个人凭证字段)显式增加个人凭证字段。知识域 v1 提供停机审计与离线目录转换，但不等同于整套旧部署迁移；请先成套备份，并按[生产部署指南](../../advanced/deployment.md)处理。
- **外部集成需调整客户端**：Agent API 统一为 Session 协议，知识查询统一为知识工具接口，旧接口不保留兼容层；CLI 改为 Node.js 22+ 的 npm 客户端，旧 Python CLI 配置不自动导入，审批与回答等待点需在网页继续。CLI 独立发布，仓库源码不代表 npm 包已发布。
- **按场景选择执行与知识组件**：Cube 需要 Linux/KVM，Container 共享宿主内核，适用于可信代码等场景，临时软件与登录态不跨执行段保留。知识能力默认开启，关闭或重新启用需更新部署并重启服务。
- **部分旧入口收敛或移除**：品牌配置统一使用新字段；对话内 HTML Preview、知识库思维导图、旧 SubAgent 专用入口与智能体待办清单工具等退出使用。HTML 文件预览、知识图谱和协作成员的人工待办继续提供。

本文汇总相对 `v0.7.3` 的变化。定时任务、Memory、基础子智能体等既有能力只列相关增强。第三方登录、MCP OAuth、模型与飞书连接的可用范围，以实际服务配置和对应接入指南为准。
