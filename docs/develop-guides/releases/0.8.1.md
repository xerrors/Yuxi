# 0.8.1 候选更新说明

本页记录 0.8.1 主线相对正式 `v0.8.0` 的变化。已发布的 `v0.8.1.beta1` 使用[标签内的升级说明](https://github.com/xerrors/Yuxi/blob/v0.8.1.beta1/docs/develop-guides/releases/0.8.1.md)。CLI 沿用独立版本。

## 使用上的变化

- **插件与连接器**　智能体可按需加载知识库和 aBridge 插件。对话中可提及连接器或设备，单个连接暂时不可用时，其他可用连接仍可工作。Skill 保留内容和脚本，运行能力由插件声明。见[插件开发](../../agents/plugin-development.md)。
- **知识检索**　支持从多个知识库检索并阅读来源原文。评估可识别已失效的参考块，删除评估会取消关联后台作业。RapidOCR 限制 CPU 推理线程数。
- **身份与设备**　本地账号支持自助修改密码。可选 OIDC 身份签发与 aBridge 集成支持个人设备，启用托管浏览器还需支持登记接口的 aBridge Server、配套浏览器发行物和 Cube 节点模板。见[aBridge 接入](../../advanced/abridge.md)。
- **会话与治理**　优化会话首屏、工具时间线和文件面板轮询，支持从调试窗口导出 Turn。兼容模型可展示推理内容并在续答时保留供应商需要的原文。共享权限选择支持服务端搜索，已删除智能体的历史活动仍计入统计。
- **文件与运维**　个人空间展示完整项目目录，删除整目录时保护会话工作目录。远程 Skill 安装支持在没有聊天 Run 时获取，内置 Skill 首次同步修正默认读取权限。Container 部署须[更新沙盒镜像及其 digest](../../advanced/container-sandbox.md#远程-skill-获取)，以提供远程获取所需的 CLI。支持只读诊断 PostgreSQL 空闲事务的来源。

## 从正式 0.8.0 升级

| 范围 | 升级结果 |
| --- | --- |
| PostgreSQL | 离线从 business 2 / knowledge 2 经插件迁移进入 5/2，再经会话状态迁移到 6/2。应用启动前完成两步。 |
| Skill 与 MCP | 转换 Agent 配置、会话快照与受影响 Skill 的当前包，删除旧依赖列并记录代码发布的连接归属。旧 Skill 激活时附带的通用工具授权取消，原有工具选择保留。若业务依赖这些工具，需显式补选。自定义部署还需审阅来源和能力范围。 |
| 运行记录 | 迁移保留既有消息、Input 和 Run。新 worker 在启动清扫及后续运行中按线程和命名空间保留最近 5 个 checkpoint，跳过有活动 Run 的线程；已失去会话的旧 checkpoint 有 7 天宽限期。 |
| 运维 | PostgreSQL 新会话及日志使用 UTC，历史时间值保持原值。若旧消息的 JSON 含 NUL 并影响读取，可单独运行 `python -m yuxi.migrations.json_nul_repair`，回读受影响消息并核对 `failed_ids`。 |

先排空并停写，备份同一时点的数据库与文件，使用目标镜像导出、审阅并应用插件迁移，再执行[会话状态迁移](../../advanced/deployment.md#会话状态迁移)。回读版本和业务数据，重跑 app-init，再启动 API 和 worker。回退需恢复配套的旧版本与备份。全新部署直接初始化目标基线。操作见[数据库与文件目录](../../advanced/deployment.md#_3-数据库与文件目录)和[插件迁移](../../agents/skills-management.md#从运行依赖升级)。

维护者可查阅[架构沿革与清理评估](./0.8.1-history.md)，了解升级起点和仍有消费者的历史路径。
