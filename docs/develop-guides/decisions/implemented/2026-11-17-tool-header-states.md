# 工具标题的中性色与明确状态

状态：implemented
类型：bug-fix
Owner：frontend/src/modules/session/ui/tools/BaseToolCall.vue

## 问题

工具标题的局部颜色覆盖使同一条调用的图标和文字层级不一致。只移除状态颜色会让折叠的文件、命令等自定义标题无法区分成功和失败；空参数也会占用无效详情行。

## 决策

### 实现方案

基础工具卡统一标题的中性色，默认使用 `gray-600`，悬停和展开使用 `gray-800`。自定义标题的失败、等待和中断文字由基础卡补齐，专用渲染器只提供确有不同语义的标签，例如设备回执的“执行结果未知”。协作事件沿用相同文字层级，保留明确状态和键盘焦点。

参数行按实际解析内容判断：空对象、空数组及空白字符串隐藏，参数对象中合法的 `0`、`false` 以及流式未完成内容仍可查看。会话历史加载提示使用浮层背景与边框，保持滚动容器内可辨认。

## 替代方案

保留各工具的状态色会继续维护重复样式；仅移除颜色而不增加文字会丢失失败信号。统一可读的中性色与状态文字满足两项要求。

## 后果

失败信息不再仅靠颜色表达。基础卡负责通用状态，专用标题需避免重复输出相同标签。此次调整不改变工具执行或授权。

## 验证

工具组件测试覆盖折叠失败标题、成功对照、空参数与非空参数，浏览器脚本检查真实组件的摘要、导航及深浅主题布局。具体执行结果记录在对应提交说明中。合成回执不证明后端工具执行。
