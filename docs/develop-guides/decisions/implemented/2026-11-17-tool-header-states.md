# 工具标题的中性色与明确状态

状态：implemented
类型：bug-fix
Owner：frontend/src/modules/session/ui/tools/BaseToolCall.vue

## 问题

工具标题的局部颜色覆盖使同一条调用的图标和文字层级不一致，折叠的文件、命令等自定义标题也需要区分成功和失败。空参数占用无效详情行，直接展示命令参数 JSON 则把命令正文和输出隔开。

## 决策

### 实现方案

基础工具卡统一标题的中性色，默认使用 `gray-600`，悬停和展开使用 `gray-800`。自定义标题的失败、等待和中断文字由基础卡补齐，专用渲染器只提供确有不同语义的标签，例如设备回执的“执行结果未知”。协作事件沿用相同文字层级，保留明确状态和键盘焦点。

耗时入口、工具组和单条工具的展开箭头紧跟摘要文字，在悬停、键盘聚焦或展开时显示。展开的工具组用左侧竖线标出所属条目。

命令工具和 aBridge 设备命令使用基础卡的 Shell 布局。卡片上部默认展示最多两行命令，点击可展开全文。下部的结果独立滚动，沿用各工具的输出和失败详情。悬停时高亮工具图标下方的竖线。其他详情继续按解析内容决定是否显示参数行，合法的 `0`、`false` 以及流式未完成内容仍可查看。

会话历史加载提示使用浮层背景与边框，保持滚动容器内可辨认。

## 替代方案

保留各工具的状态色会继续维护重复样式。仅移除颜色会丢失失败信号，因此基础卡统一使用中性色与状态文字。Shell 卡片可以折叠保留原始参数，但这会在命令与结果之间增加一个入口，因此详情直接展示命令正文与输出。

## 后果

基础卡用文字表达通用状态，专用标题只提供有不同语义的状态标签。Shell 卡片省略附加参数，命令执行仍使用原始调用参数。

## 验证

工具组件测试覆盖折叠失败标题、成功对照、参数显示和设备命令结果。使用合成回执在真实聊天页检查深浅主题下的摘要位置、键盘展开、两行预览、结果滚动及左侧悬停竖线。后端工具执行由对应链路测试验证。
