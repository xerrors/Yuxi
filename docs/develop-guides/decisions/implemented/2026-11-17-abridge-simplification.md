# aBridge 接入的配置与协议归属简化

状态：implemented
类型：simplification
Owner：backend/yuxi/modules/extensions/plugins/abridge/options.py

## 问题

设备入口、通用 MCP 和前端各自解释配置或协议，管理员凭据配置没有请求消费者，设备展示还改变了其他工具参数的可见性。接手者需要跨模块重建相同事实，本地源码构建与固定版本名称也不能共同证明部署协议。

## 决策

### 实现方案

Python 接入代码与内置 `abridge` 插件放在同一个包内。Web 设备路由直接导入设备查询和浏览器服务，Public API 直接导入托管浏览器服务，启动时从 `options.py` 收集配置。包初始化不加载插件，只有 Agent 工具的装配和提示注入经过 `plugin.py`。

设备页与 MCP 从 aBridge 配置读取同一个就绪结果：身份签发开启、内部服务来源和公开来源齐全。公开来源不回退到内部地址。每次出站直接重读数据库并复核当前用户，配置缓存不能延长旧地址有效期。Yuxi 删除管理员 Token 字段及表单状态，启动同步在同一事务清除历史保存值，避免移除敏感字段定义后泄漏旧值；aBridge 部署凭据保留，Compose 对 API/worker 的同名环境值显式置空。

通用工具卡保留参数折叠入口，不依赖全局调试模式。已有 aBridge model 解释远端回执并生成展示投影，组件负责展示，成功正文与未知结局仍严格区分。设备提示由 aBridge 插件维护，在插件激活后注入设备与沙盒的跨系统约束，chatbot 不从工具目录推断设备协议；具体工具参数由远端工具描述拥有。脚本内部 await 与外层等待超时后远端任务继续运行是不同层次。

Compose 使用官方发布镜像及固定摘要，初始化器只生成配置和密钥，不构建任意本地源码。源码协议探针与默认镜像使用同一发布版本，显式指定的源码目录缺少构建产物时测试失败。当前入口由 [aBridge 接入参考](../../../advanced/abridge.md)维护，[0.5.2 升级决定](2026-11-25-abridge-0-5-2.md)记录数据库与启动边界。

采用 aBridge 原生授权。首次统一登录及显式重新授权默认全部本人设备和能力，设置页明确告知，用户可在 aBridge 收窄。普通重复登录不恢复撤销，也不覆盖已保存策略。Yuxi 直接使用 aBridge 的授权结果。[统一登录决定](2026-11-14-abridge-identity.md)

## 替代方案

将设备服务与插件分置在两个目录，修改 aBridge 接入协议时必须跨目录核对配置、委托和工具声明。让 Web 和 Public API 统一通过插件对象访问，又会让独立使用的设备管理依赖 Agent 插件接口。

保留各处判断会继续漂移；新增插件注册和表单框架扩大维护面；完全删除设备适配会破坏图像与异步结果展示。选择收窄已有实现。继续支持任意源码构建不能保证协议版本，固定发布镜像减少维护面。默认空授权需要修改外部服务；采用已发布的默认全部授权并向用户明确说明，不在 Yuxi 复制授权逻辑。

## 后果

历史管理员 Token 覆盖在应用初始化时删除，不再能从 Yuxi 恢复，部署环境凭据仍保留。缺失公开来源的部署明确不可用，不能使用容器内部地址作为浏览器入口。配置复核增加直接数据库读取，但不受缓存失效故障影响。重新授权恢复全部本人设备和能力，之前收窄的策略需要用户重新设置。设备执行、旧数据库迁移和实际部署升级仍由外部服务及运维负责。

## 验证

旧能力不存在：代码搜索确认 Yuxi 配置及表单不再定义管理员 Token；历史字段仅保留在清理逻辑和负向测试。初始化器不再支持本地源码目录。chatbot 不再维护具体设备协议，基础卡片不再按 debugMode 隐藏参数。aBridge 部署凭据与测试 fixture 保留，不能将它们误删为无用配置。

重新引入条件：只有具备真实管理 API 消费者和独立产品需求时才重新设计凭据配置；新增协议以实际回执和消费者为依据；不为可选外部构建重建未验证的兼容承诺。

- 配置与初始化单测由 `test/unit/services/test_abridge.py` 验证；特殊字符凭据经真实环境文件回读，非法根地址在持久化与运行边界拒绝。
- `test/integration/services/test_abridge_delegation.py` 使用真实 PostgreSQL 和 HTTP 验证签发用途、配置变更、非法配置拒绝及普通连接器故障隔离。
- 前端单测与浏览器脚本验证设备展示、失败与未知状态；缺少 `Object.groupBy` 的浏览器仍可渲染。
- 本轮实际执行命令、结果与跳过原因记录在对应提交说明中。历史实现阶段的计数不作为当前版本的通过证据。

未验证真实电脑/浏览器操作、已有 aBridge 数据迁移或部署升级。本变更不启动、升级或修改现有部署与用户设备。
