# 共享页级工具栏按容器换行

状态：implemented
类型：bug-fix
Owner：web/src/components/shared/PageShoulder.vue

## 问题

页级工具栏同时包含搜索、分类和操作时，固定单行布局在窄容器中横向溢出。问题由共享组件拥有，消费者包括工具、技能、MCP、模型、智能体、知识库与定时任务页面。

## 决策

容器和操作组使用 flex 换行，左右组允许收缩并限制最大宽度，搜索框保留 280px 首选宽度但受容器约束。操作组保留右对齐。搜索模型、插槽、按钮回调和权限保持原样；不添加断点或运行时宽度监听。本项局部 CSS 修复直接记录 implemented：行为 Owner 未改变，没有待裁决的产品或持久化语义。

## 替代方案

逐页增加媒体查询会复制共享布局规则，且窗口宽度并不等于侧栏内的可用容器宽度。横向滚动会使主要操作离开当前可视范围。按实际可用空间自然换行覆盖这两类问题。

## 后果

窄容器工具栏增加高度；宽容器保留单行。自定义插槽仍负责自身的不可收缩内容，本次不承诺任意超长按钮或多个固定宽度过滤器均自适应。

## 验证

在 `web/` 执行 `node --test test/unit/pageShoulder.test.js`，确认默认搜索值、占位符、过滤器、操作与自定义搜索插槽契约。单元测试不承担浏览器布局证明。

运行 `pnpm exec vite --host 127.0.0.1`，浏览器打开 `/test/browser/pageShoulder.html` 与 `?dark`。该 fixture 挂载实际组件和 Ant Design 控件，使用项目浅深色 token；DOM 输出检查 1024、768、375、360px 容器的滚动宽度、控件边界和最小可用宽度。输入搜索、清空搜索及点击按钮后，顶部搜索值与计数用于确认事件传递；不调用业务 API。

2026-09-15 在本地 Chromium 实际执行：修复版两种主题的四种容器均通过，360px 容器 clientWidth/scrollWidth 为 358/358。将组件暂时恢复为同一分支 HEAD 原版后，两种主题的 375/360px 均失败，scrollWidth 为 704，五个控件越界；恢复修复版后再次通过。宽屏刷新、窄屏创建/导入、搜索输入与清空均完成实际点击验证。新增单元测试、定向 ESLint 和 Vite build 通过。

未验证：完整路由与侧栏组合、移动端触摸、全量消费者、自定义长文本插槽、业务 loading/error/empty 状态，以及真实业务 API。容器宽度验证不等于整页移动视口验收；本项没有生产部署或公开发布动作。
