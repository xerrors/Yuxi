# 登录页默认背景使用灰调长城插画

状态：implemented
类型：feature
Owner：frontend/src/pages/LoginView.vue

## 问题

登录卡片左侧需要一张轻量的装饰图。右侧表单承担登录操作。装饰图需要适配明暗主题，视觉层级低于表单。

## 决策

### 实现方案

`LoginView` 在 `login_bg` 为空时加载本地 WebP 长城插画，让图像铺满左栏。两种主题使用同一构图的静态插画。深色版单独调亮城墙和敌楼，以便在灰色山峦之间辨认。登录页按当前主题加载对应资源。填写 `login_bg` 时优先使用该图片。历史默认地址 `/login-bg.jpg` 加载失败时显示内置图。品牌配置见[自定义品牌](../../../advanced/branding.md)。

## 替代方案

共用一张图并用 CSS 反相可以减少资源数量。深色版需要单独调整城墙的亮度，因此两种主题各自使用一张 WebP。

## 后果

内置图随登录页本地交付。自定义图片按原图显示。768px 及以下隐藏左栏。

## 验证

- `frontend/test/browser/loginBackdrop.js` 验证默认图解码、明暗主题的显示、历史路径自定义图片及缺图回退，并检查 1024px 和 768px 下装饰图的显示状态。
