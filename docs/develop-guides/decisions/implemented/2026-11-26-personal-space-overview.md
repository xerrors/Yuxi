# 个人空间概览与文件阅读

状态：implemented
类型：feature
Owner：frontend/src/pages/WorkspaceView.vue

## 问题

用户回到个人空间时需要继续阅读打开过的文件，也需要找回 Agent 在会话中交付的原件。两类文件的时间和来源不同。宽屏并排的目录与预览会压缩正文，窄屏弹窗会覆盖导航。

## 决策

### 实现方案

Workspace 域在产品登录用户显式打开个人文件、服务端成功生成支持的预览之后，按用户把虚拟路径与打开时间写入 PostgreSQL。同一用户的更新按行加锁，每次将该路径置顶并保留最近五项。列出时在文件系统边界检查原件是否仍可读。后台读取、目录列表和独立下载不更新打开时间。API Key 不能读取或写入浏览历史。

Agent 域查询当前产品用户可见会话内成功完成的 `present_artifacts` 工具审计，按完成时间取最近的不同交付路径。结果带来源会话，可打开的归档会话继续提供交付记录。读取列表与打开原件分别检查当前访问条件，交付物可以尚未复制到「保存的产物」。

个人空间默认打开概览。侧栏以「资源」「我的知识库」「共享知识库」作为同级标题。可浏览文档的库名常驻各自分组，选择库名即可进入原目录，按已有权限阅读文件。搜索和上传位于当前内容标题旁。打开文件或交付物会用阅读器替换主区内容，关闭后回到来源概览或目录。此布局取代[旧的预览呈现方式](2026-10-08-workspace-preview-route-lifecycle.md)及[原工具栏与侧栏的上传位置](2026-10-25-workspace-drag-upload-toolbar.md)。现有文件夹上传、目录拖放和只读知识库仍使用各自的操作边界。

概览与会话面板复用[文件预览](2026-11-17-file-preview-session.md)。

概览与文件列表采用统一的页头高度、标题样式和操作尺寸。概览正文与页头两端对齐，表头沿用内容底色。上传为主操作，搜索和目录工具使用次要样式。预览顶栏使用正文色突出文件名。

## 替代方案

按修改时间排列会漏掉最近阅读的旧文档。浏览器本地历史无法在不同设备间共享打开记录。扫描已保存目录会遗漏未复制的 Agent 交付物，也无法区分用户放入其中的其他文件。通过全部会话的累计产物路径推算展示时间，会把会话其他活动误算成再次交付。

## 后果

存量库需要执行[最近文件迁移](../../../advanced/deployment.md#个人空间最近文件迁移)。打开历史从启用后开始积累，既有成功工具审计可以直接用于交付物列表。列表在可读文件系统上按路径定位，移动文件后，旧路径可能失效。同一文件在不同会话重复交付时，概览通过最近一次交付的来源会话打开原件。

## 验证

真实 HTTP 测试与 PostgreSQL 回读覆盖最近打开排序、去重、并发、用户隔离、APP 凭据拒绝和失效文件。产物测试核对项目软删除前后的归档原件字节，并排除普通文件、失败调用、其他用户及已删除会话。迁移测试在旧版 Schema 上复核版本和数据保留。

浏览器在 768 至 1440 像素宽度下从个人空间预览文件与 HTML 交付物，核对阅读器占满主区、导航保留、关闭后回到来源视图。会话文件树、会话搜索及全局搜索均验证了显式打开行为。刷新页面后最近文件保持顺序，从其他页面返回阅读器时能读到文件的新内容。下载的交付物与来源会话中的原件逐字节一致。

在隔离环境中使用两个账号和真实知识库文件核对侧栏。初次进入即可看到自有库与定向共享库的名称。从共享库的子目录打开原文后，关闭预览会回到该子目录。
