# 对话组件的图片地址和列宽权重

状态：implemented
类型：feature
Owner：frontend/src/shared/lib/chatWidgets.js

## 问题

图文列表需要让说明列获得较多空间。工具返回的图片地址也可能带一层 Markdown 链接标记。模型按这两种常见形状生成组件时，整棵组件树无法展示。

## 决策

### 实现方案

`chatWidgets.js` 在显式 `widget` 围栏的解析阶段接受单个简式图片链接 `[标签](URL)`，其中 URL 不含空白或括号。提取出的目标与裸地址使用同一校验。`WidgetNode` 用正整数 `flex` 作为分配剩余空间的权重，沿用[列布局决定](./2026-10-25-widget-composition-layout.md)中的换行基准。内置 Skill 推荐裸图片地址，并给出图文列权重示例。

## 替代方案

- 只补充模型说明。图片地址已经有说明，已生成卡片和图文比例的需求仍无法处理。
- 扩展到完整 Markdown 或 CSS。图片字段只需要一个地址，列只需要分配剩余空间。

## 后果

窄容器可将并排内容换到多行。正整数表示剩余空间的分配权重，最终列宽同时受各列的换行基准影响。远程图片加载失败时继续展示同一列表项的正文。历史回复在重新渲染时使用相同规则。
