# 会话侧边栏开始页

状态：implemented
类型：feature
Owner：frontend/src/modules/session/model/useSessionPanel.js

## 问题

右侧栏固定展示文件树。文件、协作和调试入口需要随任务按需打开，任务结束后可以关闭对应标签。

## 决策

### 实现方案

打开空侧栏时显示「开始」标签。选择工具入口时按稳定标签键打开或切换到已有标签，同时关闭「开始」。「开始」打开时隐藏加号，关闭后在最后一个标签旁显示加号。开始页入口在面板上部居中。关闭最后一个标签时回到「开始」。关闭活动标签时优先选择相邻已有标签。侧栏工具标签随 Thread 或登录身份切换重置。

会话工作区按当前协作摘要和既有调试权限装配「协作详情」「调试」入口。工作区文件和个人空间文件使用独立标签，各自显示、搜索和刷新所属文件树。工作区条目沿用当前 Thread 的 Viewer，个人文件沿用个人空间的路径和访问记录。文件预览沿用现有资源归属，放大阅读时使用面板最大化。参见[会话工作区](./2026-11-17-thread-session-reading.md)和[文件预览会话](./2026-11-17-file-preview-session.md)。

## 替代方案

合并的双树标签只能共享一个关闭和选择状态。用临时菜单提供入口会使工具选择脱离侧栏既有的标签导航。

## 后果

文件目录在打开对应标签时读取，独立占用侧栏正文。项目目录首次响应前显示加载状态。保存交付物后显示个人空间文件树。交付物菜单沿用共享弹层的焦点交接与退出行为。侧栏全高分割线支持拖拽和键盘调宽。标签状态属于当前前端视图。

## 验证

`agentPanelSections.test.js` 回读最后一个标签关闭后的开始页，以及文件轮询范围。`agentArtifactPreviewRefresh.test.js` 检查两类目录的独立读取、搜索和刷新，并保留同名文件来源和终态预览更新回归。`sessionFileTrees.js` 在实际构建页面回放会话及文件响应，检查默认页、加号、分割线上下两端拖拽、重复选择、关闭回退、条件入口、目录首次加载、空态和重试、合并刷新、同名文件预览、最大化与还原、交付物键盘下载、保存后目录归属、身份切换与深浅主题。`sessionPanelKeyboard.js` 和 `cooperationMemberSync.js` 验证键盘导航及后台协作更新时活动标签的稳定性。
