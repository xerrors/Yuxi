# 以会话快照决定默认模型和配置生效范围

状态：implemented
类型：simplification
Owner：frontend/src/modules/session/ui/SessionThreadView.vue

## 问题

时间线把页面缓存的智能体详情当作会话配置基准。详情晚于历史返回时会误报，页面打开前发生的修改也可能漏报。首条消息还会把页面展示的旧默认模型发给服务端，覆盖刚为会话选定的模型，并在接收成功后写回旧值。

## 决策

### 实现方案

智能体运行配置保存成功时复用保存反馈说明新会话的生效规则。时间线删除客户端配置比较、提示行和提示触发的滚动。普通消息只在用户选择模型时携带覆盖值，接收事务从会话快照读取默认模型。

## 替代方案

在打开会话时计算配置差异需要定义默认值、会话覆盖和协作继承的比较规则。保存反馈已能在实际修改时说明生效范围。

## 后果

配置生效说明随保存反馈展示。未显式选模型的发送省去一次会话更新请求。
