# 资源显示名称与稳定运行标识分离

状态：implemented
类型：feature
Owner：backend/package/yuxi/services/resource_display_service.py

## 问题

技能、内置工具及 MCP 的展示名称需要由管理界面编辑；标识仍用于调用、依赖、目录、禁用工具列表和协议交互。仅修改界面文本或内置源文件不具备可靠的多进程持久化与升级保留语义。

## 决策

技能源格式接受可选 `display_name`，独立于 `name` / `slug`。自建共享技能在既有管理权限下修改源文件并同步元数据；个人技能只修改认证用户的源。文件编辑与改名共用异步文件锁，锁内重读权限和元数据，失败时补偿文件内容。内置技能、内置 MCP、工具显示名使用现有 ConfigOption 表，仅读取响应应用覆盖，不修改模型调用 schema、内置源文件或 MCP 连接字段。自建 MCP 仅更新 name 字段。MCP 工具覆盖使用服务器 slug 和原始工具名的二元身份；保存前通过管理连接检查确认工具存在。

管理选项在已有可见性筛选后应用显示覆盖；可提交的 key / slug 不变，覆盖映射不会新增资源。技能依赖工具选项使用相同投影。前端在技能预览/详情、工具详情和 MCP 详情提供改名入口，保存后刷新当前视图与聊天资源候选。未保存技能文件阻止并行改名。失败保留输入并展示提示。权限仍由后端执行。

## 替代方案

修改注册表或协议工具名会破坏既有调用标识；修改内置源文件会在升级中丢失。新增数据表与迁移对当前少量名称覆盖没有必要，因此复用 ConfigOption。

## 验证

后端单元测试覆盖展示值与稳定标识分离、非法文本、权限、并发编辑、源文件补偿、内置同步，以及智能体资源配置/技能依赖选项中的显示投影。真实 PostgreSQL 集成验证内置覆盖在重连与同步后保持、并发映射无丢失、锁内元数据与权限重读；真实 JWT/TCP HTTP 验证管理员写入、普通用户拒绝、重复读取持久值和恢复默认。MCP 管理连接检查独立覆盖实际协议发现及失败。

前端 mounted 组件测试覆盖失败保留输入、保存后刷新、未保存草稿阻止改名。技能改名按钮经过实际 Vue/Ant Design 浏览器页面交互验证，使用合成 API，不构成生产登录端到端验证。工具与 MCP 页面的实际组件经桌面浏览器合成 API 验证：工具保存失败保留输入，成功后重载显示中文；MCP 服务器及协议工具改名后重载保留中文，原始工具标识、服务器 slug 和连接地址不变。该浏览器范围不包含生产鉴权、真实 MCP 服务连接、窄屏或深色主题。

后端完整单元测试 2140 项通过，显示名/技能编辑/JWT HTTP 集成 7 项通过。前端专项 16 项通过，全量 345 项通过，另有既有 Windows PDF 测试 URL 路径问题；该跨平台修复属于独立贡献。前端 lint、生产构建、文档构建和工程契约检查通过。

## 后果

PostgreSQL 与文件系统没有分布式事务；可处理的失败补偿源文件，硬崩溃后的对账仍依赖持久源。覆盖仅在管理响应和聊天展示层应用，不声明动态修改运行中模型已加载的技能内容。MCP 工具验证依赖严格管理连接检查，不依赖会吞连接异常的运行缓存。
