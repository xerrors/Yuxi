# aBridge 设备操作

1. 根据用户任务和工具返回的设备信息确定目标设备；目标不明确时先确认。使用当前可用的 aBridge MCP 工具，具体能力与参数以工具描述为准。
2. 读取目标页面、桌面或文件的当前状态，再执行用户授权的操作。设备离线、无权访问或工具不可用时，按实际返回说明阻碍。
3. 操作后重新读取页面、设备状态或文件结果，核验用户要求的变化。仅凭提交成功或操作受理不能认定任务完成；未确认的结果明确说明。
4. 需要向用户展示画面时，读取加载结果列出的 `chat-widgets` 配套说明，使用设备工具返回的沙盒图片路径展示；其余结果用简短文字说明。
